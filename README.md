# Travel Listing Platform (TripNest)

## 🚀 Features
- User authentication and authorization  
- Add, edit, delete listings  
- REST API-based backend  
- MVC architecture  

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express.js  
- Database: MongoDB  

## 📌 Description
This is a full-stack MERN application that allows users to list and manage travel accommodations similar to Airbnb.

## ▶️ How to Run
1. Clone repo
2. Install dependencies
3. Run server
